# astrbot_plugin_nailong

一个基于 [AstrBot](https://github.com/Soulter/AstrBot) 的奶龙表情包插件，支持随机发送表情、GIF 变速、GIF 倒放以及动态添加新表情。

## 功能特性

- ✅ **随机发送**：`/奶龙` 随机发送一张表情包；`/奶龙 5` 随机发送五张。
- ✅ **GIF 变速**：引用一个 GIF 动图，发送 `/变速 2` 即可加速为 2 倍速；支持 0.1 ~ 10 倍速。
- ✅ **GIF 倒放**：引用 GIF 后发送 `/倒放`，让动画反向播放。
- ✅ **添加表情**：发送 `/添加` 并附带一张图片，即可将图片保存到本地资源库。
- ✅ **透明背景支持**：完美保留 GIF 的透明通道，变速后无闪烁、无杂色。
- ✅ **自动清理**：临时文件定时清理，不占用磁盘空间。

## 安装方法

1. 将本插件文件夹（`astrbot_plugin_nailong`）放置到 AstrBot 的 `plugins` 目录下。
2. 在插件目录中创建 `resources` 文件夹，用于存放表情包图片（支持 png, jpg, jpeg, gif, webp）。
3. 重启 AstrBot 即可自动加载。

## 使用方法

| 命令 | 说明 |
|------|------|
| `/奶龙` | 随机发送一张表情包 |
| `/奶龙 3` | 随机发送三张表情包（最多 10 张） |
| **引用 GIF** + `/变速 2` | 将引用的 GIF 加速为 2 倍速（可指定 0.1 ~ 10） |
| **引用 GIF** + `/倒放` | 将引用的 GIF 倒放 |
| `/添加` + [图片] | 将图片添加到表情库（可引用图片或直接发送） |

### 注意事项
- 变速功能**仅支持 GIF 动图**，静态图片会被拒绝。
- 速度倍数支持小数（如 0.5 表示半速），超出范围会自动调整为 0.1 或 10。
- 添加表情时，图片会被复制到 `resources` 文件夹，文件名自动生成。
- 临时文件（下载的 GIF 和处理后的结果）会在一小时后自动删除。

## 文件结构

```
astrbot_plugin_nailong/
├── __init__.py          # 插件主文件
├── resources/           # 存放表情包图片（需手动创建）
└── temp/                # 临时文件目录（自动创建/清理）
```
