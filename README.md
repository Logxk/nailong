# 奶龙表情包插件

一款为 [AstBot](https://github.com/Soulter/AstrBot) 定制的多功能图片/表情包插件。除了发送随机奶龙表情包外，还提供了丰富的图片特效处理功能，包括对称、反色、旋转、镜像、变速、倒放、平移跳跃动画等。支持静态图片与 GIF 动图，可自动降级兼容。

## ✨ 功能特性

- 🐉 **奶龙表情包**：随机发送资源文件夹中的表情包，支持指定数量（最多 10 张）。
- 🔁 **对称特效**：左/右/上/下对称，基于原图生成镜像对称图像。
- 🎨 **反色**：反转图片颜色，保留透明通道。
- 🔄 **旋转**：任意角度旋转（仅整数角度 0~360°，非 90° 倍数会自动缩放并填充透明/白色背景）。
- 🪞 **镜像**：水平翻转图片。
- 🚀 **变速播放**：调整 GIF 动图的播放速度（0.1~10 倍）。
- ⏪ **倒放**：将 GIF 动图倒序播放。
- ↔️ **左右平移**：生成从左到右再返回的往复平移动画（共 30 帧，带微小上下振动）。
- 🐸 **左右横跳**：生成原地跳跃并左右摆动的动画（共 20 帧）。
- ➕ **添加表情包**：将任意图片添加到本地资源库。

> 所有特效均支持 **静态图**（PNG/JPG/WebP）和 **GIF 动图**（保留透明度与画面合成逻辑）。  
> 未引用图片时，命令将自动尝试获取发送者的 **QQ 头像** 作为素材。

## 📦 安装

1. 将本项目克隆或下载到 `AstrBot/data/stars/` 目录下：
   ```bash
   git clone https://github.com/yourname/astrbot_plugin_nailong.git
   ```
   插件文件夹名应为 `astrbot_plugin_nailong`。

2. 安装依赖：
   ```bash
   pip install Pillow aiohttp
   ```

3. 重启 AstrBot 或执行热重载，插件会自动加载。

## 🚀 如何使用

### 基础命令

| 命令格式 | 说明 |
|---------|------|
| `/奶龙` | 随机发送一张表情包 |
| `/奶龙 5` 或 `5 奶龙` | 随机发送 5 张表情包（最多 10 张） |
| `/添加` + [图片] | 将图片添加到表情包库（保存在插件 `data/nailong_resources` 中） |

### 图片特效命令

所有特效命令都需要 **引用一张图片**（回复包含图片的消息，或直接发送图片并附带命令）。  
若未引用图片，则会自动尝试获取 **发送者 QQ 头像** 进行处理。

| 命令 | 参数 | 效果 |
|------|------|------|
| `/左对称` | 无 | 以左半部分为基准生成左右对称图 |
| `/右对称` | 无 | 以右半部分为基准生成左右对称图 |
| `/上对称` | 无 | 以上半部分为基准生成上下对称图 |
| `/下对称` | 无 | 以下半部分为基准生成上下对称图 |
| `/反色` | 无 | 图片颜色反相 |
| `/旋转` | 角度（整数 0~360）<br>如 `/旋转 90` | 顺时针旋转指定角度（非整数或超出范围会返回错误提示） |
| `/镜像` | 无 | 水平镜像翻转 |
| `/变速` | 速度倍数（0.1~10）<br>如 `/变速 2` | 调整 GIF 播放速度（非动图会报错） |
| `/倒放` | 无 | GIF 倒序播放（非动图会报错）|
| `/左右平移` | 无 | 生成从左边滑入滑出的往复动画（输出 GIF） |
| `/左右横跳` | 无 | 生成上下跳跃并左右摆动的动效（输出 GIF） |

> **提示**：所有动图处理均会保留原始透明度和延时信息，并自动缩放到宽度或高度不超过 500 像素以保证网络传输效率。

## 📁 文件与目录

```
astrbot_plugin_nailong/
├── main.py               # 插件主逻辑，注册命令
├── image_utils.py        # 图像处理核心（对称、反色、旋转、GIF 操作等）
├── README.md             # 本文件
└── data/                 # 自动生成（数据目录）
    ├── nailong_resources/   # 表情包存放文件夹（支持 png/jpg/jpeg/gif/webp）
    └── nailong_temp/        # 临时文件缓存（自动清理）
```

旧版资源目录 `resources/` 会在首次启动时自动迁移到 `data/nailong_resources`。

## ⚙️ 配置与限制

- **并发限流**：通过环境变量 `NAILONG_MAX_CONCURRENT` 控制同时处理的图片数量（默认 2）。
- **输出尺寸**：生成的 GIF 宽度或高度超过 500 像素时自动等比缩小。
- **临时文件清理**：超过 1 小时未使用的原始下载图片会被后台任务自动清理。
- **安全副本机制**：每个待处理图片都会先创建独立副本，避免并发读写冲突。

## 🛠️ 常见问题

**Q：为什么 `/旋转` 命令输入非整数或大于 360° 会返回“我不会”？**  
A：这是因为插件只支持整数角度旋转，0~360° 之外的角度没有实际意义，也为了防止滥用。

**Q：GIF 处理很慢或内存占用高怎么办？**  
A：插件已对 GIF 进行帧累积渲染和尺寸限制。如果仍卡顿，可减少并发数（设置 `NAILONG_MAX_CONCURRENT=1`），或避免处理超大尺寸的动图。

**Q：如何更新表情包？**  
A：直接将图片放入 `data/nailong_resources` 文件夹，或使用 `/添加` 命令。插件会自动扫描新文件。

**Q：好友/群聊发送图片时提示“无法获取图片文件”**  
A：可能是框架未完整传递图片本地路径或 URL。请确保 AstrBot 版本较新，或检查平台适配器是否正确处理图片消息。
