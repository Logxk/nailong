# 奶龙表情包插件 (astrbot_plugin_nailong)

一个功能丰富的 AstrBot 插件，不仅可以随机发送奶龙表情包，还提供了多种图片处理功能（对称、变速、倒放、反色、旋转、镜像、万花镜、万花筒等），让你在聊天中玩出更多花样。

---

## ✨ 功能特性

- **🎲 随机奶龙表情**
  发送 `/奶龙 [数量]` 随机获取 1~10 张存放在 `resources` 文件夹内的表情包（支持 png/jpg/gif/webp）。

- **🖼️ 图片对称处理**
  对引用的图片进行对称变换，支持静态图片和 GIF 动图。
  - `/左对称`：将左半部分镜像到右半部分
  - `/右对称`：将右半部分镜像到左半部分
  - `/上对称`：将上半部分镜像到下部分
  - `/下对称`：将下半部分镜像到上半部分

- **⏩ GIF 变速**
  `/变速 <倍数>` 对引用的 GIF 调整播放速度，支持 0.1 倍 ~ 10 倍。

- **⏪ GIF 倒放**
  `/倒放` 将引用的 GIF 倒序播放。

- **🎨 其他图片处理**
  - `/反色`：颜色取反（支持静态图与 GIF）
  - `/旋转 [角度]`：旋转图片，默认顺时针 90°，支持自定义角度
  - `/镜像`：水平镜像翻转
  - `/万花镜`：八方向×五层放射铺排效果
  - `/万花筒 [面数]`：圆形扇区镜像效果，支持 6-24 的偶数面（默认 12）

- **👤 头像处理**
  上述图片处理命令在未引用图片时，默认处理目标用户头像（优先 @ 用户，其次发言者自己的头像）。

- **📥 添加表情包**
  `/添加` 将图片保存到表情库（仅管理员可用），扩充你的表情库（支持引用或直接发送图片）。

## 📦 安装

1. 将本插件克隆或下载至 AstrBot 的 `plugins` 目录：
   ```bash
   git clone https://github.com/Logxk/nailong.git
   ```
2. 安装依赖（插件会自动检测，若缺少请手动安装）：
   ```bash
   pip install -r requirements.txt
   ```
3. 重启 AstrBot。

## ⚙️ 配置

无需额外配置。插件首次运行时会在 AstrBot 数据目录（`data/plugin_data/astrbot_plugin_nailong/`）自动创建两个文件夹：

- `nailong_resources/`：存放你的奶龙表情包（放入图片即可）
- `nailong_temp/`：存放临时处理文件（每小时自动清理超时文件）

可选环境变量：

- `NAILONG_LOCAL_FACE_DIR`：QQ 客户端本地表情资源目录（`sysface_res` 下的 `apng` 目录），配置后可直接读取本机表情文件，无需 CDN 下载。
- `NAILONG_MAX_CONCURRENT`：同时处理图片的最大并发数（默认 2，范围 1-10）。

## 🎯 使用方法

所有命令均需以默认命令前缀（通常是 `/`）开头，例如 `/奶龙`。
命令后若需引用图片，请**回复**包含图片的消息，或在同一消息中附带图片；未引用图片时默认处理头像。

| 命令 | 参数 | 说明 | 示例 |
|------|------|------|------|
| `/奶龙` | `[数量]`（可选） | 随机发送指定数量的奶龙表情 | `/奶龙 3` |
| `/左对称` | - | 将引用的图片左半部分镜像到右半部分 | 回复一张图并发送 `/左对称` |
| `/右对称` | - | 将引用的图片右半部分镜像到左半部分 | 同上 |
| `/上对称` | - | 将引用的图片上半部分镜像到下部分 | 同上 |
| `/下对称` | - | 将引用的图片下半部分镜像到上半部分 | 同上 |
| `/变速` | `<倍数>` | 调整引用的 GIF 速度（0.1~10） | 回复一个 GIF 并发送 `/变速 2` |
| `/倒放` | - | 将引用的 GIF 倒放 | 回复一个 GIF 并发送 `/倒放` |
| `/反色` | - | 图片颜色取反 | 回复一张图并发送 `/反色` |
| `/旋转` | `[角度]`（可选） | 旋转图片，默认 90° | `/旋转 180` |
| `/镜像` | - | 水平镜像翻转 | 回复一张图并发送 `/镜像` |
| `/万花镜` | - | 放射铺排式万花镜效果 | 回复一张图并发送 `/万花镜` |
| `/万花筒` | `[面数]`（可选） | 圆形扇区镜像效果（6-24 偶数面） | `/万花筒 16` |
| `/添加` | - | 将图片保存到表情库（仅主人可用） | 发送一张图片并附带 `/添加` |

> **注意**：
> - GIF 处理时，透明区域会被白色背景填充，以保证兼容性。
> - 处理后的图片保存在 `nailong_temp` 文件夹，会自动清理，无需手动删除。
> - 静态图片对称/反色处理会输出 PNG 格式（保留透明通道），GIF 处理输出 GIF 格式。

---

## ⚠️ 注意事项

- 确保 `nailong_resources` 文件夹中有至少一张图片，否则 `/奶龙` 会提示"暂时还没有表情包"。
- 一次最多发送 10 张表情包，防止刷屏。
- GIF 处理需要保证文件为有效的动图格式，静态 GIF 图片无法进行变速/倒放操作。
- 若图片文件无法本地读取，插件会尝试从 URL 下载（需网络连通）。
- `/添加` 命令仅限管理员使用，其他用户无权限。

---

## 📚 依赖

- Python 3.8+
- [Pillow](https://python-pillow.org/) (PIL) —— 图像处理
- [aiohttp](https://docs.aiohttp.org/) —— 异步下载图片
- [numpy](https://numpy.org/) —— 可选，加速万花筒效果（缺失时自动回退纯 PIL 实现）
